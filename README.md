# 🚀 Rocket Sequencer (AEROTECH)

Séquenceur électronique de vol conçu pour des projets de fuséonautique (AEROTECH). 

## 🛠️ Fonctionnalités
* Gestion des allumages et des phases de vol.
* Conception électronique réalisée sous KiCad.
* Intégration de fichiers 3D pour la structure (`.step`).

## 📁 Structure du projet
* `Gerber_Finale/` : Fichiers de fabrication pour le PCB.
* `Séquenceur-backups/` : Sauversions et historiques du projet KiCad.
* `Séquenceur.kicad_pcb` : Fichier du circuit imprimé.
* `Séquenceur.kicad_sch` : Schéma électrique.

## 💻 Logiciels utilisés
* [KiCad](https://www.kicad.org/) pour la conception de la carte.
